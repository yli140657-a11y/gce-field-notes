海外站点迁移后，怎样核验 HTTPS 证书与回源链路？

确认域名和证书部署

切换前记录公网 DNS、CDN、负载均衡和源站的对应关系。验证证书有效期、完整证书链和主机名覆盖范围。对有 IPv4 和 IPv6 的域名，分别从外部网络连接。

分别验收边缘和回源

先从业务域名测试 HTTPS 和重定向，再按团队批准的方法检查源站的 TLS 配置和回源主机名。用唯一请求标识对照边缘日志和源站日志，确认登录、静态资源及 API 请求走预期路径。

记录故障及回退条件

若客户端遇到证书错误或回源失败，先区分哪个环节返回错误，再核对旧路由是否仍可恢复。保留测试时间、响应状态、证书摘要及回退记录，供后续复查。
